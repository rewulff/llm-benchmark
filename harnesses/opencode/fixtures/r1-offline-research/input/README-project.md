# Kestrel Sync Agent — document set

This folder is the document set support engineering works from. Nothing here is
generated; the files were written at different times by different teams and they
are not automatically kept in sync with each other.

| File | Written by | Covers |
|------|-----------|--------|
| `CHANGELOG.md` | Platform | every 2.x release |
| `known-issues.md` | Support Engineering | open and recently closed defects |
| `config-reference-2.2.md` | Platform | settings as of the 2.2 line |
| `config-reference-2.6.md` | Platform | settings for 2.4 — 2.6 |
| `FAQ.md` | Support | recurring customer questions |
| `meeting-notes-2026-06-16.md` | Support / Platform / Product | incident review |
| `meeting-notes-2026-04-08.md` | Platform / Support | sprint planning |
| `support-playbook-2025-11.md` | Support | troubleshooting steps |
| `wiki-tuning-guide-2026-01.md` | (owner vacant) | performance tuning |
| `log-northwind-2026-06-14.txt` | agent | customer log excerpt |
| `log-acme-2026-06-11.txt` | agent | customer log excerpt |
| `log-brightwave-2026-06-09.txt` | agent | customer log excerpt |

Every document carries its own date. Where two documents disagree, the dates and
the version they were written against decide which one still applies.
